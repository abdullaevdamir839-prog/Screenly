Проверено локально 25.10.2026. Тестирование выполнялось на временной локальной базе; реальные пользовательские данные и секреты Render не использовались.

## Автоматическая проверка

- `npm run check` — тесты бизнес-логики, ограничений, учётных записей, возрастных групп, комнат, проектов и совместной работы.
- `npm run build` — TypeScript и production-сборка Next.js.
- `npm audit --omit=dev --audit-level=high` — проверка зависимостей по npm advisories; на момент проверки известных зарегистрированных уязвимостей не найдено.

## Что не проверено без реального окружения

- Работа двух клиентов через настоящий LiveKit, отключение активных участников при закрытии, микрофоны и демонстрация экрана.
- Миграция и восстановление реальной PostgreSQL-базы Render.
- Переключение между настоящими ПК и мобильными браузерами в визуальном UI-тесте.
- Нагрузочное тестирование, эксплуатационный мониторинг, независимый пентест и юридическая готовность к публичному запуску.

Не считать этот отчёт подтверждением безопасности для массового публичного использования. Для завершения приёмки нужно проверить реальное развёртывание на Render.
