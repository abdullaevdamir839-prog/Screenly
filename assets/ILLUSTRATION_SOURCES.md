# Иллюстрации Screenly 1.4

13 SVG-иллюстраций в `public/category-art` являются **оригинальными векторными работами**, подготовленными для Screenly. Это **не** изображения unDraw.

Вдохновение по визуальному направлению: минималистичная графика, плоские фигуры, чёрные контуры, светлая палитра. Иллюстрации не копируют существующие произведения.

Почему не включены оригинальные SVG unDraw: их лицензионные условия ограничивают автоматическое скачивание, компиляцию и распространение наборами без отдельного согласия. Их можно использовать на сайте, если получить и подключить законным образом.

Если позже будут получены оригинальные SVG по разрешённому способу, их можно заменить в папке `public/category-art/` с теми же именами файлов.
