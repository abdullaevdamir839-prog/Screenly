Screenly 1.7 — Online Beta (закрытое тестирование)

1. Рабочий сайт и LiveKit из 1.6 сохранены.
2. Добавлена поддержка DATABASE_URL для PostgreSQL: сохранение пользователей, друзей,
   сообщений, комнат, проектов и жалоб в JSONB-состоянии с блокировкой строки для записи.
3. Запросы API обёрнуты в транзакции; при ошибке откат изменений.
4. Режим локального теста без DATABASE_URL сохраняет старую JSON-базу.
5. Добавлены db:init, db:import, /api/health, start:hosted и шаблон Render.
6. Для онлайн-режима обязателен HTTPS SITE_ORIGIN и DATABASE_URL.
7. Новые ограничения: остаётся ТОЛЬКО закрытая бета. Самостоятельно выбранный возраст
   НЕ заменяет проверку, поэтому нельзя запускать открытую платформу 13+.

Инструкция для Windows: ДЕПЛОЙ_НА_RENDER_WINDOWS.md
Не пересылай .env.local, database URL, API Secret или файлы пользователей.
