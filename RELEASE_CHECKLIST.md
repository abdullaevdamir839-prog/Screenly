# Screenly 2.0 — проверки перед открытием массового доступа

Сейчас приложение рассчитано на **закрытое тестирование**. Все пункты ниже должны быть подтверждены на реальном сервере перед снятием ограничений.

## Данные и доступ

- [ ] Убедиться, что PostgreSQL на Render сохраняет существующие аккаунты после деплоя.
- [ ] Сделать резервную копию через `npm run db:backup` в доверенном окружении.
- [ ] Проверить восстановление копии **только в отдельной пустой тестовой базе**.
- [ ] Убедиться, что секреты LiveKit, `DATABASE_URL`, коды доступа и `.env` не попали в GitHub.
- [ ] Проверить вход, выход, восстановление сессий и удаление аккаунта на нескольких тестовых пользователях.

## Совместная работа

- [ ] Два пользователя подключаются в одну комнату, передают экран и звук.
- [ ] Аннотации работают лишь с разрешения владельца экрана.
- [ ] Отмена штриха не удаляет рисунки другого пользователя.
- [ ] Создатель закрывает комнату; новые подключения становятся невозможными.
- [ ] Переподключение после кратковременного обрыва сети.
- [ ] Проверка в Chrome, Firefox и Edge на Windows, macOS и Linux.
- [ ] Проверка страницы «только для ПК» на Android и iOS. Это не блокировка API и не средство безопасности.

## Безопасность сообщества

- [ ] Провести независимую проверку безопасности регистрации и API.
- [ ] Организовать работающие модерацию, жалобы, правила и контакт для обращений.
- [ ] Не открывать случайные встречи несовершеннолетних до проверки возраста и мер защиты.
- [ ] Перенести лимиты запросов в общий datastore до запуска нескольких серверных инстансов.
- [ ] Нагрузочно протестировать данные и заменить общую JSONB-строку таблицами для масштабирования.

## Публикация

- [ ] Настроить собственный домен и HTTPS.
- [ ] Добавить политику конфиденциальности и правила использования с учётом региона запуска.
- [ ] Проверить мониторинг ошибок, бюджет и возможности восстановления после отказа.
- [ ] Провести контролируемое тестирование с несколькими независимыми пользователями.

Релизная сборка и автоматические тесты **не означают**, что эта контрольная проверка пройдена.
