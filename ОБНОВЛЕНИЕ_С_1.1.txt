SCREENLY 1.2 — КАК ОБНОВИТЬ

1) Останови старую версию: в CMD/PowerShell нажми Ctrl+C.
2) Распакуй новый ZIP полностью в отдельную папку.
3) Перенеси из старой папки в новую .env.local (в корень, рядом с package.json).
4) Сохрани аккаунты: скопируй data\screenly.json, предварительно сделав резервную копию.
5) Дважды нажми START_SCREENLY.cmd. Не закрывай окно.
6) Открой http://localhost:3000/community и зайди в аккаунт.
7) Нажми слева «Творчество»: там новые категории, поиск, мастерские и форматы занятий.

Если сайт не запускается, запусти PowerShell в новой папке:
npm.cmd install
npm.cmd run check
npm.cmd run build
npm.cmd run dev

Важно: .env.local содержит пароли и API Secret, никому его не отправляй.
Это закрытая тестовая версия, не готовая публичная 13+ площадка.
